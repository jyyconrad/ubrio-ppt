# 成对制作样例

输入与判断点在 [cases.json](cases.json)，制作源码在 [make_examples.cjs](make_examples.cjs)，配套组件在 [native.cjs](../../scripts/native.cjs)。均为合成材料，不是实际公司业务数据。

样例覆盖指标、趋势、目标对比、多序列、表格、流程、矩阵、责任链、图片证据、封面、中文混排、显式配色参考。最后一项只验证主题参数变化，不证明任意旧PPT母版读取或原位编辑。

每项最终PPTX及其实际渲染图存于 `output/`；内部转换PDF和渲染记录随对应预览目录保留。[目视记录](output/visual-review.md)链接全部实际预览。这里的样例是可重复工具测试，不是独立模型12类乘3次评测，也不是PowerPoint编辑往返证明。维护者选用LibreOffice仅用于这组可选参考渲染，不构成使用本技能的依赖。

复现方式见 [运行环境](../../references/generate/setup.md)。省略 `--case` 会按cases.json生成全部样例；`evidence-synthetic.png` 是合成台账的真实渲染，作为证据页独立图片对象使用。原始输入JSON仅用于维护者样例，用户仍可直接给普通材料。

## 使用时关注

- 目标对比：两序列、三个类别、真实工作簿与图表缓存一致；965/1000=96.5%。
- 台账和中文混排：单元格可编辑、中文完整、单位清楚；不对未知原因作结论。
- 流程/矩阵：原生文字与形状，不是整页图片；可读容量依实际字体检查。
- 图片证据：截图只是合成台账，不推断不存在的延期；旁边的判断文字保持原生。
- 配色参考：只改变颜色，数值与第三例相同。字体或尺寸变化必须重新验证。

正式发行还需PowerPoint中的修改保存重开、独立盲评、留出输入及模型重复生成；不得以本组脚本固定样例的通过率宣称模型成功率。
