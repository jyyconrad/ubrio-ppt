# 大纲方法参考

## 人话（在大纲完成，不放到制页）

正文页的口吻在大纲阶段定稿。制页只抄这些字段；缺了或仍是抽象名词堆，回到大纲改，不在 SVG/`page_spec` 里另写一套总结。

每页正文种子至少包含：

| 字段 | 写成什么 |
| --- | --- |
| 标题 | 一句判断，能当众说出口 |
| 主观点 | 谁 / 在什么场景 / 遇到什么问题 / 要做什么 |
| 人话四要素 | `who` `scene` `problem` `action` 四个都填 |
| 听众记住什么 | 一句，回答“这页讲完听众带走什么” |
| 作用 / 证据 / 表达 / 风险 | 仍按下面“页面最小语义” |

机器核对：`scripts/svg/gates/plain_language.py` 的 `check_outline(seed)`。禁用词以该文件 `BANNED_JARGON` 为准。封面、章节页可用判断句标题代替主观点；结束页要有一句带走的话。

## 页面最小语义

正文页通常应能回答：

- **标题：** 这页给出的判断是什么，而不只是“业务概况”之类话题词。
- **作用：** 这页在整册中承担背景、判断、解释、比较、方案、行动还是决策。
- **证据：** 哪些数据、事实、案例、政策或用户反馈能支撑判断。
- **表达建议：** 适合图表、表格、流程、对比、案例、截图还是文字归纳。
- **风险：** 哪个口径、假设或缺口最容易在制稿时被误写。

这些内容可以写成自然语言、表格或用户模板，不要求机器字段齐全。固定页和轻量叙事页按实际需要精简。`thesis`、`proves`、`dominant`、`label` 不在此列，必须按 [叙事与形状](narrative-shape.md) 写上，不能并进一句自由叙述。

## 证据缺口

- 缺少数值时，不编造百分比、金额、排名、样本量或时间点。
- 来源冲突时，保留冲突及各自口径，不替用户武断选一个。
- 预测、目标、预算、内部测算与实际结果必须分开。
- 公开来源应保留发布者、标题、日期和链接；来源尚未取得时明确写为建议补充。

## 容量检查

- 一页同时承担多个独立结论、超过两类主要证据或需要多张复杂图表时，考虑拆页。
- 两页证明同一结论且证据高度重复时，考虑合并。
- 章节只有一页且没有节奏或组织价值时，通常并入相邻章节。
- 长章节可增加章节页，但章节页不能替代正文结论。

## 默认 Markdown 示例

```markdown
## 第二章 经营判断

### 5. 核心区域增长未能抵消成熟区域下滑
- 人话：销售负责人 / 看全国达成 / 成熟区域下滑把核心区域的增长吃掉 / 先核对成熟区域口径再调目标
- 主观点：核心区域在增长，但填不上成熟区域的下滑，所以全国目标仍未达成。
- 听众记住什么：先分清两个区域，再解释总目标为什么没到。
- 作用：解释整体目标未达成的结构性原因
- 证据：区域销售额、同比、目标完成率；来源为“区域销售”工作表
- 表达建议：区域贡献瀑布图 + 右侧原因摘要
- 风险：目标完成率为内部测算，需核对公式缓存与统计截止日
```

示例只说明信息深度，不限定标题数量、字段名或输出格式。
