# Anti Pattern: AI Flavor

## 问题表现

AI 味是「视觉装饰过度 + 文字修辞过度」的组合信号：单独一条不致命，同页命中多条时读者会立刻判定“这是 AI 生成的”，信任度归零。

视觉侧：

- **彩虹卡片**：四个并列痛点、能力、举措或其他同级模块“每个模块一种颜色”，并列卡片每卡一个色相（蓝/绿/紫/橙轮着排）的顶边条、描边或图标，色相差异不承载任何语义。
- **卡片边缘彩条**：在卡片左/右/顶/底边复制全高或全宽彩条，把装饰当作层级；它与卡片边框、编号和标题重复强调，是典型模板化语法。
- **装饰符号当信息**：✦ ✨ ⚡ 🚀 等符号做项目符号或强调前缀（如“✦ 越积越厚”）；→ 箭头当万能列表符（“→ 用户锁定在单一生态”）。
- **均质模板脸**：圆角卡片 + 左上角小图标 + 短标题 + 两行灰字的四联排，页页同构。
- **无信息量装饰**：霓虹 glow、半透明玻璃拟态、渐变装饰球到处出现，说不出各自承载什么信息。

文字侧：

- **空洞对仗口号**：两段四到六字短语对偶、无对象无数字（“越积越厚，越难逾越”“正向循环，越转越快”“命门清晰、应对有方、终局可观”）。
- **「不是 A，而是 B」句式滥用**：一套 deck 内反复出现（“不是又一个平台，而是开放标准层”“不是简单叠加，而是自我强化系统”）。
- **热词堆砌**：赋能 / 抓手 / 闭环 / 底座 / 飞轮 / 护城河 / 生态 / 引擎，一页多次或跨页复读。
- **破折号与万能总结**：“——”高频出现；每段结尾都挂一句“正因如此……”式总结。
- **中英夹杂标签腔**：“标准即入口——最高价值节点”式的抽象名词标签串。

## 修复规则

每条 = 判定信号 → 替换动作。改写示例只是方法示意，一律按当前页真实内容重写。

视觉：

1. 并列卡片出现 ≥2 个装饰性色相 → 全 deck 收敛到唯一主色；卡片统一浅灰底 + 细中性边框，差异用编号、数值和标题内容表达。仅语义功能色保留（风险=红、对照=琥珀），规则见 `contract-visual-token-core.md` 单一色系。
2. 卡片左/右/顶/底边的全高/全宽彩条 → 直接删除，不改成另一条边，也不缩短后继续贴边；用 surface 明度、留白、字重字号、编号或小面积状态标签建立层级。渐变描边 / 渐变文字同样删除；渐变只用于确有立体或影像意图的页面（读 `svg-shape-3d-isometric.md`），不做卡片默认装饰。
3. 文字内容出现 ✦ ✨ ⚡ 🚀 等符号或 emoji → 删符号。列表符用编号或主色小方点/短横；强调用主色或字重。SVG 图标槽位的 emoji 禁令见 `contract-icon-usage.md`，本条管文字层。
4. → 箭头做并列列表符 → 只在表达“从 A 到 B”的转化、流向或因果时用箭头；普通并列一律编号。
5. 四联排均质卡片（图标+标题+两行灰字页页复用） → 先判断四项信息角色是否真同质：不同质就换承载结构（读 `anti-pattern-fixed-template-monotony.md` 与 `gold-structure-composition.md`）；确属同质并列则改为“编号 + 深色短标题 + 灰正文”，去图标或统一为单色小图标。
6. glow / 玻璃拟态说不出承载的信息 → 回到平面默认：白或浅灰底 + 细边框 + 纯色文字；发光投影最多保留给全页唯一强调对象，纪律见 `svg-effect-glow-shadow.md`。

文字：

7. 对仗口号 → 改成“对象 + 可验证变化 + 量级”的判断句（“越积越厚，别人拿不到” → 写清沉淀了什么数据、多大规模、为何难复制）；有真实数字写数字，没有就写机制，绝不编造。
8. 「不是 A，而是 B」 → 全 deck 最多保留 1 次（放最关键定位页）；其余直接陈述 B 是什么、边界在哪。
9. 热词（赋能/抓手/闭环/底座/飞轮/护城河/生态/引擎） → 换成具体机制：谁、做什么、导致什么可观察结果。行业通名确需保留时一页最多 1 个，且后面必须跟证据。
10. “——”每页最多 1 处 → 多余的改冒号、句号或拆成两句。
11. 段尾万能总结句 → 删。结论只出现在标题（判断句）和收束页，不在每段重复。
12. 中英夹杂标签腔 → 中文正文不夹英文抽象名词；英文只保留专有名词、产品名和真实指标名。

## 正例对照

低 AI 味页面的稳定特征（按此校准，不是照抄模板）：

- 白或极浅灰底；全 deck 唯一主色，只用于重点数字、编号和少量强调。
- 卡片 = 浅灰底 + 细中性边框 + 统一圆角，无渐变、无 glow。
- 列表 = 编号 + 深色短标题 + 灰色正文，无装饰符号。
- 强调靠“主色大号数字”承载（数字即视觉锚点），不靠形容词和发光。
- 文案直接写事实与数字（“路由延迟 < 100 毫秒”“命中率 20%~30%”）——信息本身即卖点，不靠修辞撑场。

## QA

进渲染前逐条自检，命中即回改：

- 并列卡片之间是否存在 ≥2 个色相的纯装饰差异？
- 文字内容里是否出现 ✦ ✨ ⚡ 🚀 或任何 emoji？箭头是否用在了非转化关系上？
- 数热词出现次数：同页 >1 或同词跨页复读即改。
- 全 deck「不是…而是…」是否超过 1 次？
- 每个渐变、glow、半透明面板能否一句话说出它承载的信息？说不出就删。
- 对每句口号问“给谁、多少、凭什么”：答不出就补数字、改机制描述或降级为事实句。
- 对照正例特征：主色是否唯一、强调是否落在数字上、卡片是否素面。

- 整页只有口号、缺证据缺行动 → 读 `anti-pattern-low-density-slogan.md`。
- 多页结构同模板 → 读 `anti-pattern-fixed-template-monotony.md`。
