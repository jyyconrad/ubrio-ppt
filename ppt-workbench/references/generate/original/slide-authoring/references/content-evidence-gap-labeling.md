# Content: Evidence Gap & Caliber Labeling

## 内容说明

不能编造数据。缺证据时标注缺口，并说明需要补什么。

两态边界（对齐 `contract-content-density.md` 与 content-writing 的 `outline-evidence-gap.md`）：下列缺口标签是**工作态**产物，只用于 outline 阶段和内部修补清单（对应大纲的 `evidence_gap=true`）。**最终 PPTX 正文不保留任何缺口/草稿词**（`需补充`/`待补充`/`示意`/`预计` 等会被 `contract-svg-self-qa.md` 最终态硬检查拦截）——成稿缺证据时只允许写口径边界句（如“内部测算，待商务确认”“风险边界/假设条件”），或删槽、ask_user 补料。

工作态缺口标签（仅限 outline / 内部修补清单，不得进入最终态渲染）：

- `需补充：指标口径/周期/来源`
- `需补充：代表案例、对象、结果`
- `需确认：责任主体与完成时间`
- `来源：用户素材 / 需补充权威来源`

### 口径脚注：哪些数字最终态必须标口径

下列三类内容在**最终态是合法表达**，不是要清除的草稿词，但必须带口径脚注，与普通结论句区分开：

1. **内部测算 / 方案报价类数字**：本方测算的规模、投入、回报等数值，脚注“内部测算口径，待商务确认”或同等表述。
2. **厂商或第三方案例数据**：引用厂商公开案例、第三方评测或客户方披露的数据，脚注标明数据来源方（如“据 XX 厂商披露”），不能把厂商口径写成本方结论。
3. **能力示意 / 非真实统计的演示内容**：用于说明能力或流程的示意数字、示意曲线、示意截图，脚注标“能力示意”，避免受众误读为真实运营数据。

预测值必须写成预测：`预计`、`目标`、`规划达到` 等措辞保留，不得把预测值改写成已发生事实（如把“预计增长 40%”写成“已实现增长 40%”）。

### 判定归属

“这个数字该不该标口径”是**语义判断**，机器校验不了，必须进内容审核清单（见 `contract-review-baseline-discipline.md` 的口径脚注核对条款）。脚注写法上并入来源行，不单独另起一行——整页仍然最多一条来源行。

## 视觉说明

（工作态）缺口标签用弱提示样式，不要抢主结论，可放在卡片底部或 `source-note`，不得生成页面 footer；最终成稿不落缺口/草稿词，改用一句口径边界句或口径脚注，与来源共用同一弱化行。

## SVG说明

工作态缺口文本作为 `<text>` 保留，命名到 `evidence-gap` 或 `source-note`；进入最终态渲染前，未补齐的缺口必须替换为口径边界句或删槽，不把草稿词提交渲染。口径脚注同样落在 `source-note`，与来源、编写日期共用同一行，不新增文本节点。
