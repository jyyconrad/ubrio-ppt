# SVG Self QA Contract

## 内容说明

提交前逐项对照当前页输入，确认标题、核心结论、卡片、步骤、数字、周期、责任和来源没有遗漏。

跨元素连贯性检查（只查“遗漏”不够，还要查“错序/失义”）：

- 同页编号、序号必须连号且与语义顺序一致（如卡片写成 03 却排在第 2 位即错序）。
- 压缩改写标题、正文后，逐条回对输入包：确认主体、数值、时态、口径未被改写走样——压缩措辞可以，改变事实、主体或时态不行。

最终态文案硬检查：

- 可见 `<text>` 中不得出现 `待补充`、`需补充`、`待精确`、`示意值`、
  `示意性`、`合理推断`、`预计`、`待补口径`、`待补数据` 等草稿态表达。
- 证据不足时先补证据；补不了就降级为明确风险边界或询问用户，不把草稿词当最终结论。
- 来源说明最多一句话，整页最多一个 source-note / `evidence-source`。

## 视觉说明

检查主标题权重、主体承载率、卡片内部分层、深浅背景对比、来源说明弱化和图标统一。

可读性硬检查：

- 主体正文通常不低于 15px。
- 每段文本的字号已与容器宽度对齐：放进卡片/列的文本按 `容器内宽 / 每字宽`（中文每字宽≈font-size、
  内宽≈卡片宽×0.92）估算过单行字符数，装不下的已先压短语、拆 `<tspan>` 或降密度，而不是把长句
  塞进窄卡靠渲染层自动缩字号兜底；无背板长句右边界 `起始x + 估算宽 ≤ 1216`。
- 图表、流程、架构和时间线标签通常不低于 12px。
- 来源、口径和注释不低于 11px，且只保留一句话。
- 如果出现 6 个以上重内容卡片、每卡 3 条以上 bullet、或流程/技术图标签需要缩到微型字，
  先重排、摘要化、拆页或询问用户，不调用 renderer。
- 同一类 overlap / overflow（卡片正文裁断、强调句压出框、列表项溢出等）连续两次仍未解决时，
  停止局部 patch，强制重排为更低风险布局：四卡改 2x2，密集横排改上下双区，
  长列表改左右两栏且每栏 ≤ 2 个要点，并相应削减每槽文本量。
- 不用 emoji 当图标；整套 deck 使用统一图标槽位、编号系统或文字标签。
- 汇报类页面默认禁止：(a) 与数据语义无关的整形粗描边——`stroke-width` ≥2px 包住卡片/容器四边的整圈轮廓；
  (b) 卡片左缘或顶缘的装饰色条（没有独立数据/状态含义、纯粹为分栏或"好看"而加的实心色块）。
  允许保留：数据图形自身的语义描边（图表线、gauge 弧、图例色块）、≤1px 低对比 hairline 分隔线、表格线、
  以及小面积语义标记（状态点、图例色块、"当前/选中"胶囊标签）。需要强调层级时改用填充深浅分层、
  留白分组、字重字号差异或小图标，而不是加粗边框或加色条。

## SVG说明

硬检查：

- 根节点是单个 `<svg>`，`viewBox` 为 16:9。
- 没有 `<script>`、`foreignObject`、`symbol/use`、远程资源、DOCTYPE/ENTITY。
- 所有 `<text>` 都有 `fill`、`font-family`、`font-size`。
- 深色背景上没有 `#000000`、`black` 或未设色文本。
- 所有关键文字仍是 `<text>` / `<tspan>`。
- 内容在 `0..1280`、`0..720` 内，无重叠和越界。
- 同一 baseline 上的文本盒不能互压；“标签 + 长正文”必须使用内联 `<tspan>`、
  预留标签宽度后的正文起点，或拆到下一行。
- 卡片正文每行 ≤ 22-26 个中文字符，4 卡横排正文每行 ≤ 18-20 个；超出先拆成多行独立 `<text>`（逐行显式 y）
  或压短语，不靠缩字号或越出卡片边界硬塞；同行内强调才用内联 `<tspan>`（仅覆写 fill/font-weight/font-size，不带 x/y/dy）。
- 图标槽位带 `data-icon-id` 和 `data-icon-box`。
- 没有 emoji、混合图标风格、页脚式多行来源、不可读小字或草稿态表达。

自检不能替代他审：本文件是同一作者写完自查“我有没有漏”，判断视角有限；正式的“这页到底合不合格、分数可不可信”他审基准见 `contract-review-baseline-discipline.md`。
