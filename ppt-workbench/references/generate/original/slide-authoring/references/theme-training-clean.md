# Training Clean Theme

## 内容说明

适合培训、课程、SOP、练习任务。内容强调目标、步骤、误区、案例和迁移。

## 视觉说明

视觉 token：

- `background`: `#F8FAFC`
- `surface`: `#FFFFFF`
- `title_text`: `#1E293B`, `36-44px`
- `body_text`: `#334155`, `16-20px`
- `source_text`: `#64748B`, `11-13px`
- `accent`: `#F59E0B`
- `border`: `#E2E8F0`

视觉要亲和但不幼稚。用编号、步骤条、练习卡、检查表提高可操作性。

## SVG说明

步骤编号用 accent，正文保持深色。练习页底部可放 `actions` 或 `homework` 分组。
