# Red Gold Government Theme

## 内容说明

适合党政学习、国企党建、政策宣贯。内容强调精神、内涵、实践路径和落实机制。

## 视觉说明

视觉 token：

- `background`: `#FFF7ED` 或 `#8A1538`
- `surface`: `#FFFFFF`
- `title_text`: `#7F1D1D` 浅底 / `#FFFFFF` 深底, `40-52px`
- `body_text`: `#3B1F1F` 浅底 / `#FFEFD5` 深底, `16-19px`
- `source_text`: `#8A6A4F`, `11-13px`
- `accent`: `#D4A843`
- `border`: `#E7C78B`

红金只做庄重层级，不滥用渐变和装饰。政策原文与实践动作必须分层清楚。

## SVG说明

章节页可用深红背景浅色文字；正文页建议浅底白卡，提高阅读效率；整页背景选型与参数统一见 theme-background-policy 颗粒（photo_dark/paper_light/pattern/纯色四形态）。
