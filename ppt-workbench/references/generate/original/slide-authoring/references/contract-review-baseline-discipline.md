# Review Baseline Discipline Contract

`contract-svg-self-qa.md` 是同一作者写完自检；本颗粒是**他审方法**。二者互补：自检查"我有没有漏"，他审查"这页到底合不合格、分数可不可信"。在线 `slide_qa_reviewer` 子代理复核单页时面临同样的自评通胀风险，同样适用本纪律。

## 外部基准防通胀

**没有基准物的审核分数必然通胀**：审核 agent 只看渲染图打分，天然给高分。视觉审核必须同时给三个输入，缺一不可信：

- 渲染图；
- **基准物**：固定参考图 / deck 设计契约 / 已确认过审的同册页面（做打分锚点）；
- 密度 / 可读性纪律。

只给渲染图的打分不采信。基准物是把"好不好看"从主观感受锚定成"与已确认基准的差距"的唯一手段。

## 机器门禁先行

**校验器过了才轮到语义审**。机器只能查连号、禁词、越界、字号下限、整页背景等硬信号；这些没过，语义审无意义。顺序固定：机器门禁（校验器 / self-qa 硬检查）→ 视觉审 → 内容审。别用语义审去兜机器能查的错。

## 打分下限即打回线

审核必须有**硬阈值 + 具体修复项清单**，不能只给一个模糊评价。

- 打分低于下限即打回（阈值可配；原则是"必须存在硬阈值"，一个具体数字比"感觉还行"可靠）。
- 打回必须附**具体修复项清单**（哪个元素、什么问题、怎么改），不是笼统"再优化一下"。没有修复清单的打回等于没审。

## 视觉审核与内容审核分开跑

两类审核**输入不同、分开跑**：

- **视觉审核**输入 = 渲染图 + 基准物 + 密度纪律；判观感、层级、明暗节奏、组件一致性。
- **内容审核**输入 = 渲染图 + **页面输入包**（seed / page_spec）；判事实、口径、连贯性。缺了输入包，内容审核无法判断"这个数字该不该是这个值"。

"该不该是 02""这个改写是否失义""这个数字该不该标口径"都是**语义判断**，机器查不了，必须由内容审核承担。

## 语义复核清单（内容审核逐条过）

① **编号 / 序号跨元素连贯**：同页卡片号、步骤号连号且与语义顺序一致（如卡片写成 03 却排在第 2 位即错序）。
② **改写保义**：标题、正文压缩改写后逐条回对输入包——压缩措辞可以，**改变事实、主体、时态不行**（如"人工分析需求"被改写成"白天分析需求"即失义）。
③ **必须出现的数据点逐条落版**：输入包标注的"必须出现的数据点"逐条在页面出现，且**值与口径未被改动**。
④ **口径脚注核对**：内部测算 / 方案报价、厂商或第三方案例数据、能力示意 / 非真实统计内容，是否都带了口径脚注。
⑤ **预测值不写成已发生**：预测、目标、规划值必须写成预测，不得表述为已经发生的事实。

## 修复循环与归因

- **修复循环上限**（如 3 轮）：同一页反复打回超过上限即停止自动修复，升级人审，不无限循环。
- **审核输出必须带页标识**（page_id）：无页标识的审核结论无法归因到具体页面，视为无效输出。
