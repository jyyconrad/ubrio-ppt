# Layout Density Contract

## 内容说明

版面要让受众快速扫出“结论、证据、行动”。留白用于分组和层级，不用于掩盖内容不足。

## 视觉说明

- 主标题必须是 SVG 内容层第一视觉锚点，普通内容页主标题 `36-46px`。
- 章节标识、页码、进度导航和顶部标签由框架层生成，不进入 SVG 内容层。
- 主体正文通常不低于 `15px`；密集表格、流程/图表标签通常不低于 `12px`；
  来源、口径和注释不低于 `11px`，且来源说明最多一句话。
- 正文主体通常占页面宽度 78-92%、高度 60-78%；矩阵、象限图、对比表、行动表和风险矩阵应优先取高值。
- 所有 SVG 页型都要先估算主体 bbox，而不是只看单个卡片：排除 `source-note`、footnote、citation
  和框架 chrome 后，记录主体 `x/y/w/h/bottom` 与 `width_ratio=w/1280`、`height_ratio=h/720`、
  `bottom_ratio=bottom/720`。如果 bbox 显示主体偏窄、偏矮或整体偏上，先改主体结构比例，再调装饰。
- 普通 content 页的主体承载区应延展到页面下半部，通常至少覆盖到 `y≈592-640`。
  除封面、章节分隔、结束页外，不允许标题和主体内容只停在上半屏。
- 对比矩阵、象限图和表格类结构的主体底边通常不早于 `y≈608`；如果底边早于 `y=592`，
  必须增大主体区域高度、增加行高/象限高度或把结论/行动条纳入主体底部，而不是只把来源文字放到底部。
- 标题区与正文区应作为一个整体做垂直平衡：顶部安全边距、标题到主体的间距、主体底部到弱注释/
  页脚安全区的距离应接近，不要把正文整体压在上半屏或把底部留成空场。
- 汇报类页面默认铺满 1280x720 画布：排除 source-note 与页脚安全区后，页面底部或右侧
  出现约超过 25% 画布面积的连续空白，属于必改级问题，不是可保留的观感偏好；
  该口径与渲染前自检、视觉审核共用。
- 若底部出现大面积空白，必须先重排、增大主体承载区、把证据/风险/行动条下沉到内容区底部，
  或拆成下一页；内容确实少时，用放大字号、增大卡片、拉开组间留白把版面撑满，
  而不是把内容缩在上半页；不要用居中的少量卡片制造“精美但空”的正文页。
- 卡片内部连续空白超过卡片高度 35% 时，必须补信息或改布局。
- 3 个信息组不要机械拉成 3 张巨大空卡，可用左主结论 + 右证据或 2+1。
- 6 个以上重内容卡片、每卡多条 bullet、或技术流程图标签必须缩到微型字时，
  先改成时间线/表格/摘要+证据区，必要时拆页或询问用户；不要通过不可读字号硬塞。
- 同一 deck 的图标和视觉语言要统一，不用 emoji 与正式业务卡片混排。

## 机器底线

以下阈值可脚本预筛，命中即 **warning 级**机器信号，不是硬性 blocking：

- 页面 `<text>` 节点数 ≥ 12。
- 页面 shape（非文本图形元素）数 ≥ 10。
- 所有文字字号 ≥ 11px。

不足以上任一阈值不等于必错——封面、目录、章节分隔页等固定页型天然文字/图形元素少，应豁免；但只要触发 warning 就必须转人工过目，不能自动放行。这组阈值把“版面过素”从纯语义判断变成可脚本预筛信号：机器先筛出嫌疑页，语义判断仍由人工/reviewer 补齐；`gold-page-patterns.md` 的最后检查步骤引用的就是这组阈值。

## SVG说明

推荐区域：

- `title-band`: `x=64 y=58 w=1152 h=84..100`
- `key-message`: `x=64 y=136..152 w=1152 h=64..80`
- `main-content`: `x=64 y=200..240 w=1152 h=416..472`，普通正文页应把主体结构或底部行动/风险/证据带延展到 `y≈608-648`
- `source-note`: `x=72 y=688`

元素不得越界或互相遮挡。
source-note 是内容层底部弱提示，视觉上可放在页脚区域，但语义上不是 `footer`；
整页最多一个，最多一句话。

## 版式选择策略

先按内容形态选一个低风险版式模式，再把裁剪好的短槽填进去；不要先堆满内容再硬塞进固定模板。

- agenda / 议程类（多个并列议题或问题）：不要默认四张等宽重卡。优先「2x2 决策矩阵」或
  「左侧结论 + 右侧四问题短列表」；右侧列表每项一行短标题，解释压成短语放第二行。
- content / 论证类（一个判断 + 几条证据）：优先「左侧价值层/对比 + 右侧三点短证据」，
  每条证据 ≤ 2 行；条数多于 3 时改时间线、表格或摘要+证据区，不并排堆等宽重卡。
- 选模式的判据是关系而非数量：并列/对照关系用矩阵或左右分栏，递进/因果关系用时间线或流程，
  中心-卫星关系用放射图；找不到清晰关系时退回「左结论 + 右证据」最稳的两栏结构。
