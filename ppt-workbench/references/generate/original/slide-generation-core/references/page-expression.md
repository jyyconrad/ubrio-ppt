# Page Expression

单页表达必须满足：

- 一页一义：标题必须是观点句。
- 结论先行：先给判断，再组织支撑、解释、影响和行动/风险。
- 多块举证：通常用 2-4 个内容模块举证，而不是一段长文。
- 阅读路径清晰：让用户自然走完“结论 -> 支撑 -> 解释 -> 记忆点”。
- 高密度不是堆字，而是用卡片、图表、指标、表格和流程承载信息。
