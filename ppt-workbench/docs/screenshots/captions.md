# 效果图说明

这些图用来展示中文高密度业务汇报页：结论先行，用机制、指标、流程、架构和诊断把一页讲完。

首图是技能实际导出的可编辑页，使用合成演示数据，没有水印。

其余 7 张是包内版式效果参考。页脚带有原图水印，水印予以保留。它们不是去掉水印后的交付稿，也不是真实客户数据。

**标题：** 四项运营指标均改善，下一步把三项机制固化到日常作业。
